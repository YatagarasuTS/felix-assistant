# Безопасность

Феликс слушает микрофон, управляет окнами компьютера и — через «Феликс Link» — телефоном, поэтому к безопасности относимся серьёзно.

**Нашли уязвимость?** Не публикуйте её в открытых Issues. Напишите через [Security Advisories](https://github.com/YatagarasuTS/felix-assistant/security/advisories/new) этого репозитория: что не так, как повторить, на какой версии. Ответим и выпустим исправление.

Что важно для проекта:
- связь с телефоном — только в локальной сети, AES-256-GCM с ключом из кода сопряжения, защита от повтора сообщений;
- управление телефоном — только по команде с компьютера, служба специальных возможностей ничего не читает в фоне; экран передаётся, только пока открыто окно «Телефон»;
- ключ API Anthropic хранится зашифрованным (Windows DPAPI) и отправляется только в Anthropic.
