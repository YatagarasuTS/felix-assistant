Забота

Напоминать попить воды
Раз в час, только когда ты за компьютером. Голосом: «напоминай пить воду».
Звать размяться
Каждые 50 минут Феликс потягивается и зовёт тебя. Голосом: «напоминай размяться».

Погладь Феликса мышкой по голове — ему понравится. Ещё: «сделай селфи», «запусти помидор», «камень, ножницы, бумага», «загадай число», «загадай загадку», «подними настроение».

Гардероб

Аксессуары Феликс надевает руками, а переодеваться уходит за ширму. Голосом: «Феликс, надень корону», «переоденься в космос», «сними очки», «оденься по погоде», «надень что-нибудь».

Голос

Голос работает без интернета (нейросеть Piper). Можно подключить свой голос.

Тон
Громкость

Свой ИИ-голос по HTTP

Любой синтезатор с HTTP-доступом (XTTS, Silero, Coqui, облачный API). В адресе и теле запроса {text} заменяется фразой. Ответ — wav/mp3/ogg или JSON с полем audio (base64).

Микрофон

Нейросеть

Обычные команды Феликс выполняет сам и без интернета. Свободные вопросы («почему небо голубое», «придумай тост») он задаёт нейросети — через твой собственный аккаунт Claude или локальную модель на этом компьютере.

Модель — Claude Opus 5.5; если она откажется отвечать, Anthropic сам повторит запрос на запасной модели. Подписку claude.ai (Pro, Max) сторонние программы по правилам Anthropic использовать не могут — для них нужен именно ключ API.

Локальная модель (Ollama)

Установи Ollama и скачай модель, например qwen2.5:7b. Работает без интернета, нужна мощная видеокарта или терпение.

Телефон

Приложение «Феликс Link» для Android 9+: команды Феликсу с телефона (голосом или текстом, ответ — его голосом), управление телефоном с компьютера (экран, приложения, доставка еды, такси, карты), звонки телефона на экране компьютера, будильники и таймеры на телефоне, «где мой телефон», включение компьютера по сети. Телефон и компьютер должны быть в одной сети Wi-Fi.

Управление телефоном с компьютера

Окно «Телефон»: экран телефона на компьютере (Android 11+) — клик мышью работает как нажатие пальцем, есть «Назад», «Домой», список приложений и ввод текста с клавиатуры. На телефоне включи «Феликс Link — управление с компьютера» в специальных возможностях. Голосом: «Феликс, покажи экран телефона», «на телефоне назад», «напиши на телефоне …».

Приложения для дел

Выбери, какое приложение телефона открывать: «Феликс, закажи пиццу» — доставку, «вызови такси до работы» — такси, «маршрут до вокзала» — карты, «купи наушники» — магазин. Феликс откроет приложение и впишет запрос в поиск; заказ и оплату подтверждаешь сам.

Включение компьютера с телефона

Кнопка «⏻ Включить компьютер» в «Феликс Link» будит выключенный компьютер по сети (Wake-on-LAN). Для этого в BIOS материнской платы должен быть включён Wake on LAN, а в свойствах сетевой карты Windows — «Пробуждение по магическому пакету».

О программе

Открытый код. Феликс — свободная программа под лицензией MIT: код программы и «Феликс Link» открыт, его можно изучать, менять и предлагать улучшения. github.com/YatagarasuTS/felix-assistant

Приватность. Распознавание речи и голос работают на этом компьютере. В интернет уходят только: вопросы к нейросети (в Anthropic или на твой сервер Ollama — смотря что выбрано), запросы погоды (Open-Meteo), курса валют (ЦБ РФ), Википедии и поиска трека. Записи голоса не сохраняются и никуда не отправляются. Экран телефона виден здесь, только пока открыто окно «Телефон», и никуда больше не передаётся.
